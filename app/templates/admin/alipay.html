① 支付宝应用信息

在支付宝开放平台，打开你的应用详情页就能找到这些内容。

本站用它核对「付款确实是打给你的」，防止伪造的付款通知。

② 密钥

密钥只保存在服务器上，加密存放，保存后不会再显示出来。

注意：这里要填「支付宝公钥」，不是你自己上传的「应用公钥」。两个填反了，付款会验签失败。

③ 付款通知

买家付款后，支付宝会通知本站，订单才会自动变成「已付款」。

{% if cfg['notify_url'] %}

系统会让支付宝把通知发到：{{ cfg['notify_url'] }}

{% else %}

不填也能用：系统会每隔几秒主动向支付宝查询付款结果，只是不如通知及时。

{% endif %}

超过时限没付款，订单自动关闭，占用的卡密库存会释放。

④ 启用收款

测试一下

保存后点一下，系统会向支付宝发起一次只读检查（不会产生订单、不扣款），确认密钥填对了。
